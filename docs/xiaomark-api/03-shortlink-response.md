# 响应数据及返回码

- Source: https://xiaomark.com/help/api/shortlink-response
- Fetched: 2026-02-24 17:14:20 +0800

## 响应数据格式

全部接口返回的数据均为 json 格式，并配合 HTTP 响应状态码来表示接口调用是否成功。

#### 调用成功返回的 json 数据示例如下：

```
{
	"code": 0,
	"message": "请求成功",
	"data": {
		...  // 与接口功能相关的业务数据
	}
}
```

#### 调用失败返回的 json 数据示例如下：

```
{
	"code": 10,  // 返回码，参考下文
	"message": "请求数据格式错误",  // 错误信息，参考下文
	"data": {}
}
```
